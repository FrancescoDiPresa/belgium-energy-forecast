# belgium-energy-forecast

Day-ahead electricity price forecasting for Belgium using ENTSO-E and weather data, with an LLM layer for natural-language explanations and Q&A over Elia reports.

## Status

🚧 Work in progress. Currently on milestone 1: setup and data ingestion.

## Scope

**In scope (v1)**
- Day-ahead electricity price forecasting for the Belgian bidding zone
- Model comparison (ARIMA, Prophet, XGBoost) with experiment tracking in MLflow
- Interactive Streamlit dashboard, publicly deployed
- Natural-language explanations of forecasts generated by an LLM
- Question answering over Elia/ENTSO-E reports (RAG with ChromaDB)
- Reproducible pipeline (Docker, GitHub Actions)

**Out of scope**
- Trading advice or arbitrage strategies
- Intraday and balancing markets
- Real-time operational forecasting

## Planned tech stack

Python, pandas, scikit-learn, statsmodels, Prophet, XGBoost, DuckDB, MLflow, Streamlit, Claude/OpenAI API, ChromaDB, Docker, GitHub Actions.

## Data sources

- [ENTSO-E Transparency Platform](https://transparency.entsoe.eu/): day-ahead prices
- [Open-Meteo](https://open-meteo.com/): historical weather and forecasts
